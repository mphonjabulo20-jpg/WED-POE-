Bloom & Bean

Project documentation | October 30, 2026

1. Overview

Bloom & Bean is a coffee brand website created as a front-end project using HTML, CSS, and JavaScript. The website presents the brand, highlights coffee products, offers subscriptions, promotes workshops, and includes contact and functionality sections.

The design uses warm earthy colours such as cream, brown, terracotta, and sage green to reflect a premium artisan coffee identity.

2. Project Goal

  • Promote the Bloom & Bean brand
  • Display coffee products
  • Encourage subscription sign-ups
  • Present workshop opportunities
  • Share coffee blog content
  • Allow users to contact the business

3. Technologies Used

  • HTML5
  • CSS3
  • JavaScript
  • Google Fonts
  • Font Awesome Icons

4. Project Files

File Description
index.html Main landing page for the website.
about.html Brand story, mission, vision, and sourcing information.
product.html Shows available coffee products and shop layout.
subscriptions.html Displays monthly coffee subscription plans.
workshop.html Workshop booking and registration page.
blog.html Article cards and coffee-related blog content.
contact.html Contact form and business contact details.
functionality.html Interactive demo page with search, filter, cart, and dark mode features.
style.css Shared CSS for the website styling.
script.js Interactivity such as mobile menus and demo alerts.

5. Website Structure

The website includes a consistent navigation bar across all pages:

  • Home
  • About
  • Product
  • Subscriptions
  • Workshop
  • Blog
  • Contact

Each page follows the same brand identity and uses a responsive layout for mobile devices.

6. Design Style

The site uses a premium coffee brand aesthetic. The visual design includes:

  • Warm cream backgrounds
  • Dark brown typography
  • Terracotta, orange accent buttons
  • Rounded cards and borders
  • Soft shadows and clean spacing

This design creates a natural and premium café feel.

7. HTML Structure

Each page is built with standard semantic elements such as:

  • header
  • nav
  • main
  • section
  • footer

These elements improve readability, structure, and accessibility.

8. CSS Features

The CSS defines the visual identity of the entire project. It includes:

  • a reset for margin/padding
  • body styling and fonts
  • button styles
  • navigation layout
  • card layouts
  • mobile responsive media queries

The button class `.btn-terracotta` is the main call-to-action style used throughout the site.

9. JavaScript Functionality

The `script.js` file manages front-end interactions:

  • Hamburger menu toggle on smaller screens
  • Highlight active page in navigation
  • Prevent form reload on submit
  • Display demo alert messages
  • Show “subscription selected” confirmation prompts

All interactions are client-side demos and do not connect to a real backend.

10. Page-by-Page Summary

10.1 Home Page

The home page introduces the brand and includes a hero section, product presentation, and call-to-action buttons.

10.2 About Page

Explains the business story, mission, vision, and ethical sourcing practices.

10.3 Product Page

Lists coffee products with titles, pricing, and add-to-cart buttons.

10.4 Subscriptions Page

Contains subscription plans with monthly pricing and email newsletter signup.

10.5 Workshop Page

Allows visitors to choose a workshop date and submit a booking request.

10.6 Blog Page

Displays coffee blog cards and brewing tips.

10.7 Contact Page

Contains contact details and a message form.

10.8 Functionality Page

Shows a more advanced interactive demo with cart, filters, search, and theme management.

11. Responsiveness

The project is designed to be mobile-friendly. Media queries adjust the layout for smaller screens by:

  • collapsing the desktop navigation into a hamburger menu
  • stacking content into single columns
  • adjusting spacing and card widths

12. Strengths of the Project

  • Clean and professional layout
  • Consistent branding throughout the site
  • Simple and responsive design
  • Practical front-end interactivity
  • Clear marketing structure for a coffee business

13. Possible Improvements

  • Connect forms to a real backend or email service
  • Add a real shopping cart and checkout
  • Create product detail pages
  • Implement database-driven subscriptions and bookings
  • Add user authentication and admin panel

14. Conclusion

Bloom & Bean is a static website designed for a premium coffee business. It combines branding, product marketing, and simple interactivity in one cohesive web experience. The project is a strong front-end demo for a coffee brand and can be expanded into a larger e-commerce or booking platform in the future.
