# Bloom & Bean Website

A static coffee brand website for Bloom & Bean, designed to showcase products, subscriptions, workshops, blog content, and customer enquiries.

## Project overview

This website includes:
- Home page
- About page
- Product catalog
- Subscription page
- Workshop page
- Blog page
- Contact page
- Enquiry page
- Interactive shop functionality page

## Tech stack

- HTML5
- CSS3
- JavaScript
- Font Awesome icons
- Google Fonts

## How to run

Because this is a static website, you can open the pages directly in a browser.

Option 1:
- Open `index.html` in your browser.

Option 2:
- Run a local server in the project folder, for example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Features

- Responsive layout for desktop and mobile
- Coffee product catalog and interactive shop filters
- Search and category filtering on the functionality page
- Cart functionality for demo shopping
- Dark mode toggle for interactive demo
- Newsletter sign-up form demo
- User enquiry form with validation logic
- Brand-focused earthy coffee aesthetic

## Notes

- The website uses local image assets stored in the `images/` folder.
- Some pages use JavaScript-driven interactions in `script.js` and inline script blocks.
- It is a frontend static site and does not connect to a backend database.
